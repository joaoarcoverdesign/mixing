02

Tipografia

Urbanist (sans, 300–800) é a voz estrutural — títulos uppercase, labels, corpo. Lora (serif) é usada só em itálico — a "voz humana": subtítulos, aspas, ênfases, índices.

03

Espaçamento

Sem grid fixo — praticamente tudo usa clamp(). Duas variáveis centrais fazem o trabalho de layout em todas as páginas:

--px: clamp(20px, 5vw, 72px);   /* padding lateral fluido — nav, seções, container */
--ease: cubic-bezier(.22,1,.36,1);  /* easing único de toda transição/animação */
Escala de valores fixos que aparecem no CSS (gaps, padding de pills, ícones)

06

Ícones

Sem icon font / biblioteca — SVG inline, 24×24, desenhado à mão. Logos de rede social ficam brancos fixos sobre fundo de marca; setas de UI herdam currentColor.
